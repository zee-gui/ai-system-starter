# Home, the front door

Start here. This is the dashboard of your second brain.

> **Golden Rule:** every note answers at least one future question. If not, do not create it.

## You
- [[Me]] : who you are, what you want, how you work (fill this first).

## Maps of Content
- [[Projects-MOC]] : everything you are building.
- [[Ideas-MOC]] : seeds not yet projects.
- [[Learning-MOC]] : reusable solutions and insights.
- [[Research-MOC]] : investigations and spikes.
- [[Business-MOC]] : models, pricing, market.
- [[Career-MOC]] : skills, identity, achievements.
- [[Technologies-MOC]] : tools, frameworks, patterns.

## The system
- [[conventions]] : how this vault works (read first).
- [[frontmatter-spec]] : the note schema.

## The five folders
- `0-Home` the front door. `0-Inbox` raw capture that drains. `1-Projects` anything with an end and
  a deliverable. `3-Garden` what you write and mature. `4-Tools` your operating manual (templates,
  scripts, skills). Lifecycle lives in `status`, never in a folder.

## Quick start
1. New project? Copy `4-Tools/templates/project.md` into `1-Projects/`.
2. Learned something reusable? `3-Garden/learning/`.
3. An idea? `3-Garden/ideas/` with `status: seed`.
